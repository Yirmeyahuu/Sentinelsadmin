# 🛡️ Sentinels

Welcome to **Sentinels** — a gamified cybersecurity learning platform for Cybersecurity Fundamentals. A Thesis Study of DevInnovate.
Empower your classroom with interactive tasks, real-time progress tracking, and a leaderboard that sparks friendly competition.

---

## 🚀 Features

- **Tiered Cybersecurity Challenges**  
  Novice, Junior, and Senior tasks designed to build skills step-by-step.
- **Faculty Dashboard**  
  Visualize student progress, manage deadlines, and monitor activity with beautiful charts.
- **Dynamic Leaderboards**  
  See top performers in real time, motivating students to climb the ranks.
- **Notifications & Deadlines**  
  Never miss an important event or submission.
- **Modern UI**  
  Built with Tailwind CSS and Chart.js for a sleek, responsive experience.

---

## 🛠️ Tech Stack

| Layer         | Technology                |
| ------------- | ------------------------ |
| **Frontend**  | Django Templates, Tailwind CSS, Chart.js, Alpine.js, HTMX |
| **Backend**   | Django (Python)          |
| **Database**  | MySQL, Firebase Firestore|
| **Auth**      | Firebase Authentication  |
| **Cloud**     | Firebase Cloud Platform  |

---

## ☁️ Why Firebase **and** MySQL?

- **Firebase Firestore** powers real-time data, notifications, and seamless cross-device sync.
- **MySQL** provides robust, relational data storage for core academic records and analytics.

Together, they give Sentinels the best of both worlds: speed, scalability, and reliability.
